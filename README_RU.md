# WALKAI V7 — Natural AI Voice

V7 переводит голосовой слой с браузерной озвучки на серверный AI TTS и добавляет настоящий голосовой диалог.

## Запуск на компьютере

1. Установить Python 3.11+.
2. Открыть терминал в папке V7.
3. `pip install -r requirements.txt`
4. Задать переменную окружения `OPENAI_API_KEY`.
5. Запустить: `uvicorn server:app --host 0.0.0.0 --port 8090`
6. Открыть `http://localhost:8090`.

Для телефона сервер должен быть доступен по HTTPS или через безопасный туннель. Ключ API хранится только на сервере и не должен попадать в HTML/JavaScript.

## Что реально делает V7
- `/api/tts` генерирует естественную речь через `gpt-4o-mini-tts`.
- `/api/ask` принимает запись голоса, транскрибирует её через `gpt-4o-mini-transcribe`, формирует ответ через GPT и возвращает текст; затем фронтенд озвучивает ответ через `/api/tts`.
- Если сервер/API-ключ не настроены, приложение честно показывает сообщение вместо подмены на старый роботизированный голос.

### Важно для микрофона и камеры
На телефоне страница должна открываться через **HTTPS**. На скриншоте браузер показывает `content://media`, поэтому Android/Chrome не предоставляет странице доступ к микрофону и камере. Это ограничение браузера, а не кнопки WALKAI. `getUserMedia()` доступен только в защищённом контексте; после размещения проекта на HTTPS микрофон запрашивает разрешение нормально.
